# TaskFlow 🚀

TaskFlow is a clean, modern, and interactive To-Do List Single Page Application (SPA). Designed to help users manage their daily tasks effortlessly with a seamless user experience, smooth UI transitions, and local data persistence.

## ✨ Features
- **Add Tasks:** Quickly add new tasks using the input field (supports pressing `Enter`).
- **Inline Editing:** Edit task text directly without leaving the page.
- **Task Completion:** Toggle tasks to mark them as done (with visual strikethrough styling).
- **Delete Tasks:** Remove individual tasks easily.
- **Bulk Actions:** "Clear All" button to wipe the board clean (safely disabled when empty).
- **Real-time Counter:** Automatically calculates and displays the number of remaining tasks.
- **Data Persistence:** Integrated with browser `localStorage` so your tasks are saved even if you refresh or close the browser.

## 🛠️ Tech Stack
This project was built from scratch without relying on heavy UI libraries, focusing on core React principles and custom CSS.

- **Framework:** [React.js](https://react.dev/) (via Vite)
- **Styling:** Vanilla CSS (CSS Modules & CSS Variables)
- **State Management:** React Hooks (`useState`, `useEffect`)

## 🚀 Getting Started

To run this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/AzrielNaufal-Dev/TaskFlow.git

2. **Navigate to the project directory:**
   ```bash
   cd TaskFlow
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```
5. Open `http://localhost:5173` in your browser.
